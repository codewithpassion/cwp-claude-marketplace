# Remember

```
a place to reflect on what worked and what didn't, and to capture important details for future reference.
```

## Process

1. Review the current context, what did we work on? What are the important details, decisions, and information that you want to remember for the future?

2. Update your own memory with these findings. This is for you - no one else will see this.

3. For project persistence, copy this to the project memory tree in ./.claude/memory/*. - This is still private for you, but it will be available for future reference in the context of this project.

4. Commit them.
